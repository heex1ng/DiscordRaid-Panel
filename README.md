# Discord Raid Panel

A simple command line interface (CLI) tool written in GoLang created to destroy Discord servers. (Nuke)

## Prerequisites

* **GoLang** installed on your operating system.
* A Discord Bot Token with Administrator permissions on the server.

## Quick Start

1. Open your terminal or CMD in the project folder.
2. Run the application:

```bash
go run main.go
```

3. Paste your Bot Token when prompted and select an option from the menu.

## Features

* Channel removal system.
* Create +100 channels
* Easy to Use
* CLI Interface:** Clean terminal interface with built-in screen clearing.
